## Publicação no GitHub Pages

1. No repositório `thiagominacio/thiagominacio.github.io`, mantenha uma cópia da versão anterior caso precise reverter.
2. Envie **os arquivos e pastas que estão na raiz deste pacote** (não envie o ZIP como único arquivo nem crie uma pasta extra envolvendo tudo).
3. Confirme `index.html`, `style.css`, `main.js`, `favicon.svg`, `.nojekyll`, `assets/` e `projetos/` na raiz do repositório.
4. Remova arquivos antigos que não fazem parte desta versão, para evitar conflito com folhas de estilo e scripts de versões anteriores.
5. Em **Settings → Pages**, escolha **Deploy from a branch**, `main` e **/(root)**, caso ainda não esteja configurado.
6. Acesse https://thiagominacio.github.io/ após a publicação.

O endereço GitHub Pages fica público. Antes de compartilhar o site, confirme que as imagens de projetos profissionais podem ser divulgadas e que não exibem dados confidenciais.

### Atenção na publicação GitHub Pages

O `index.html` e os arquivos `.html` dos projetos devem estar nos caminhos exatos:

- raiz: `index.html`
- pasta `projetos/`: cada página `.html`
- pasta `assets/`: as imagens dos cases anteriores

Se um case retornar 404, confira na aba Code do GitHub se o arquivo consta realmente dentro da pasta `projetos` na branch `main`, e não somente no arquivo ZIP local.

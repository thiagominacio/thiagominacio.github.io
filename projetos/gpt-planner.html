GPT → Planner: consulta de tarefas com IA

Integração experimental de um GPT personalizado com Power Automate e Microsoft Planner Básico para consultar tarefas e recuperar informações em formato estruturado, sem alteração de registros.

GPT personalizadoActions / HTTPPower AutomateMicrosoft Planner BásicoJSON
01 · CONTEXTO

O problema que motivou a solução

A consulta de tarefas costuma exigir alternar entre diferentes telas e filtros. A ideia deste experimento foi testar se uma interface em linguagem natural poderia consultar informações de um plano por meio de uma integração controlada.

ObjetivoConectar um GPT personalizado a dados do Microsoft Planner sem conceder permissões de edição, permitindo visualizar tarefas e atributos relevantes para acompanhamento.
02 · DESENVOLVIMENTO

O que foi realizado

  • Criado um plano de teste no Microsoft Planner Básico, separado do ambiente corporativo.
  • Configurado um protótipo de integração entre GPT personalizado, chamada HTTP e fluxo Power Automate.
  • Testada a consulta somente leitura a tarefas, buckets, responsáveis e prioridades.
  • Tratado o retorno como informação estruturada para apresentação pelo GPT.

Como funciona o processo

Fluxo simplificado do MVP. A integração descrita é de leitura e não cria, edita ou exclui tarefas.

03 · EVIDÊNCIAS E COMPETÊNCIAS

O que este projeto demonstra

Funcionou em teste

Consulta a informações de tarefas do Planner Básico.

Somente leitura

Nenhuma operação de criação ou atualização foi parte do MVP.

Retorno estruturado

Uso de dados em formato JSON na integração.

Limitação identificada

A mesma abordagem não acessou diretamente os planos Premium usados no cenário corporativo.

O experimento exigiu entender endpoints, configuração de ações do GPT, conectores, formatos de resposta e diferenças entre Planner Básico e Planner Premium. Também evidenciou que um fluxo funcionar tecnicamente não significa que esteja licenciado para produção.

04 · TRANSPARÊNCIA

O que ainda não está pronto ou não é público

Limites do caseO Planner Premium possui arquitetura e conectores diferentes do Planner Básico. A integração corporativa com planos Premium não ficou concluída. O uso de gatilho HTTP no Power Automate pode exigir licenciamento Premium; o projeto não deve ser apresentado como integração de produção homologada.

Arquitetura ilustrativa. Nenhum token, URL de fluxo, plano corporativo ou dado interno é publicado.

05 · EVOLUÇÃO

Próximas melhorias possíveis

  • Reavaliar o caminho técnico autorizado para Planner Premium/Dataverse.
  • Validar permissões, autenticação e licenciamento em ambiente de teste.
  • Documentar contratos JSON e criar cenários adicionais de erro e acesso.

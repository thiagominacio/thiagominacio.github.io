Cofrinho Multimoedas — Java

Aplicação de console utilizando abstração, herança, polimorfismo e coleções em Java.

JavaPOOHerançaPolimorfismoArrayList
O PROJETO

Programação orientada a objetos aplicada a moedas.

Aplicação de console em Java para adicionar, remover e listar moedas em Real, Dólar e Euro e calcular um total convertido para reais. O exercício foi construído com classes, herança, encapsulamento, polimorfismo e uma lista de objetos.

Código real disponível: seis classes Java originais do projeto, com um pacote para baixar e testar localmente.

Evidência 1 · Trechos reais do código

A classe abstrata define o contrato de conversão. A classe Cofrinho percorre os objetos e usa o método sobrescrito converter() de cada moeda.

package principal;

// Classe abstrata que representa uma moeda genérica
public abstract class Moeda {

    // Encapsulamento: atributo privado
    private double valor;

    // Construtor que recebe o valor da moeda
    public Moeda(double valor) {
        this.valor = valor;
    }

    // Getter para permitir acesso controlado ao valor
    public double getValor() {
        return this.valor;
    }

    // Método abstrato para exibir informações da moeda
    public abstract void info();

    // Método abstrato para converter a moeda para Real (R$)
    public abstract double converter();
}

            // Polimorfismo: cada tipo converte do seu jeito
            total += m.converter();
        }
        return total;
    }

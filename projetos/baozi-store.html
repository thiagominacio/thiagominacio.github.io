Baozi Store API

Uma API REST desenvolvida para simular o cadastro e a consulta de clientes, produtos e pedidos de uma pequena loja.

DesenvolvimentoProjeto acadêmicoJava · Spring Boot · Spring Data JPA · H2 · Postman

Telas e evidências

Imagens e registros utilizados para documentar o desenvolvimento.

O desafio

O exercício exigia traduzir requisitos de uma operação comercial simples em entidades, endpoints HTTP e persistência de dados.

O que desenvolvi

Implementei a aplicação em Java e Spring Boot, separando modelo, repositório e controller, usando Spring Data JPA e H2. Validei os endpoints de cadastro e consulta no Postman.

O que o projeto demonstra

  • Entidades Cliente, Produto e Pedido.
  • Endpoints de cadastro, listagem, consulta e exclusão.
  • Persistência com Spring Data JPA e banco H2.
  • Testes HTTP com requisições e respostas JSON no Postman.
Projeto de estudo publicado no GitHub; não representa sistema comercial em produção.
